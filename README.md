# 🐦 Java Flappy Bird

A Flappy Bird game developed using Java.

## About the Game

A bird-control game where the player navigates through obstacles and tries to achieve a high score.

## Built With

- Java
- Java Swing / AWT (if used by the project)

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the required Java SDK.
4. Run the game's main class.

## Features

- Bird movement
- Obstacles
- Collision detection
- Score tracking
